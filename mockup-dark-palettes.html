Dokumentasi proyek

Teks utama menggunakan warna terang yang sedikit diredam. Sidebar dibuat lebih gelap, sementara panel dan blok kode sedikit lebih terang daripada area baca.

Warna aksen dipakai untuk tautan di dalam dokumen dan aksi utama. Teks sekunder tetap terbaca untuk path, metadata, dan navigasi.

Contoh kutipan: palet yang cocok perlu dilihat pada dokumen panjang, bukan hanya pada sidebar.

Catatan implementasi

  • File yang dibagikan bisa diakses melalui path aslinya.
  • File privat memerlukan akses workspace.
  • Judul, teks biasa, dan kode punya hierarki yang berbeda.
# Contoh Markdown

## Instalasi
npm install
npm run dev

Gunakan tab Markdown untuk membandingkan tampilan blok teks mentah.

Warna tanpa hitam pekat
